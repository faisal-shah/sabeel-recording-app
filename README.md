# Hikam Foundations Class Recordings

Product and research artifacts for the Sabeel Institute recording platform. The app lets adult students listen to class recordings in-app while giving staff a clear accountability ledger.

The planned stack targets Android and web first, with the codebase kept ready for future iOS support.
